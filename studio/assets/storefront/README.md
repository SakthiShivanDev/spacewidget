# Everyday Store reference assets

These product images were generated with the built-in imagegen tool for the user's Shop screen reference. The reference supplied the composition, product subjects and blue/lavender palette. The page layout, all lettering, category controls and product actions are native editable widgets; no screenshot is used as the page UI.

- `hero.jpg`: wide indigo product still life, with space on the left for native headings.
- `lamp.jpg`: warm black desk lamp photograph for the Home product.
- `backpack.jpg`: dark navy backpack photograph for the Accessories product.
- `Manrope.ttf`: variable Manrope font from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/manrope), distributed under the included `OFL-Manrope.txt` license.

JPEG exports are optimized from the original generated PNGs. The server embeds the images and font as data URIs, so Flutter mobile, Studio and the web app share the same assets without extra image hosting or CORS configuration. Changing existing demo product images does not change prices, inventory, carts or order snapshots. Favourites are held in the running app's state; this design does not add an account wishlist backend.
